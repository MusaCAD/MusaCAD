The pull request text is yours to write. Flathub refuses submissions whose text was
generated by an AI assistant, and closes for good a submission whose AI disclosure is
untrue (its reviewers look at the source repository). These are the facts to draw on.

  https://github.com/MusaCAD/MusaCAD; LGPL-3.0-or-later.

  single portal-picked file is not enough. DXF works with nothing else; DWG conversion is a

  recording it as created by "Canva AI" (source type: composite with trained algorithmic
